# Data Science: Exploratory Data Analysis

Coursework scripts for exploratory data analysis (EDA) with pandas.

## Contents
- `exp_3_exploratory_data_analysis.py`: EDA on the India air-quality dataset (head/tail, column info, summary statistics, missing values)
- `aqi.csv`: monthly air-quality readings (PM10, SO2, NOx, PM2.5, NH3, O3, CO, benzene, AQI)
- `mall_customers.csv`: customer age, income and spending-score data

## Run
```bash
pip install pandas matplotlib seaborn
python exp_3_exploratory_data_analysis.py
```
The script was exported from a Google Colab notebook and reads the CSV from the current folder, so run it from this directory.
